# Мое питание — дневник КБЖУ

Мобильное Android-приложение на **Flutter** для учёта калорий, белков, жиров и углеводов (КБЖУ), расчёта индивидуальной суточной нормы и поиска продуктов по названию и штрихкоду.

## Основной функционал
- **Дневник питания:** распределение приёмов пищи по дням, автоматический пересчёт КБЖУ по граммовке, индикатор прогресса дневной нормы.
- **Расчёт нормы КБЖУ:** автоматический расчёт по формуле Миффлина — Сан Жеора с учётом пола, возраста, роста, веса, уровня активности и цели, а также ручная корректировка.
- **Поиск продуктов и справочник:** гибридный поиск по встроенному справочнику (330 готовых блюд, овощей, фруктов и базовых продуктов) и базе **Open Food Facts API** с локализацией выдачи и кэшированием запросов.
- **Сканер штрихкодов:** считывание штрихкодов с упаковок через камеру устройства (`mobile_scanner`) с корректной обработкой отказа в разрешении.
- **Мои блюда:** создание пользовательских блюд с валидацией формы, привязкой штрихкода и приоритетным отображением в поиске.
- **Локальное хранение:** сохранение дневника, настроек нормы и пользовательских блюд в локальной базе данных SQLite (`sqflite`).

## Технологический стек
- **Язык и фреймворк:** Dart, Flutter
- **Архитектура и управление состоянием:** MVVM (`ChangeNotifier` + `Provider`)
- **База данных:** SQLite (`sqflite`)
- **Сеть и API:** `http`, Open Food Facts REST API
- **Работа с устройством:** `mobile_scanner`, `permission_handler`
- **Логирование и тестирование:** `logger`, `flutter_test` (unit-тесты, тесты ViewModel и widget-тесты)
